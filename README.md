# Willian Albarello · Portfólio & Currículo Interativo

Portfólio e currículo interativo de Willian Albarello — Engenheiro de Software & Sistemas: tecnologia assistiva (Centelha/FINEP), gamedev/computação gráfica em C++, engenharia reversa e infraestrutura.

## Tecnologias

- React 19 + TypeScript
- TanStack Router & Start
- Tailwind CSS v4
- PGLite (banco de dados local/offline-first)
- Vite

## Destaques Visuais e Funcionalidades

- Retrato Hero Interativo: sequência dinâmica ao passar o mouse com grafismos Kenê do Acre, glifos ASCII / GlyphWave, ondas topográficas de Fourier e colagem duotone com pigmentos urucum e jenipapo.
- Suporte multilíngue completo: Português, Inglês, Espanhol, Francês e Hebraico (com suporte a RTL).
- Painel de Acessibilidade: alto contraste, ajuste tipográfico, compatibilidade com leitor e modo de redução de movimento.
- Otimização para impressão e exportação direta para PDF.

## Desenvolvimento Local

```bash
npm install
npm run dev
```

Acesse `http://localhost:8080` no navegador.

## Build para Produção

```bash
npm run typecheck
npm run lint
npm run build
```
